# Pre-Aggregated Daily Activity Telemetry and Email Verification Lifecycle

We maintain a dedicated `dailyActivity` collection keyed by `{ userId, date: 'YYYY-MM-DD' }` (UTC) and updated via atomic `$inc` upserts (`fastify.recordDailyActivity`) on Note creation/update, Post-Mortem creation, and Flashcard creation/review so `GET /dashboard/summary` serves the 12-week contribution heatmap, 14-day study velocity, Inbox count, due Flashcards count, and active Campaign/Notebook readiness in a single bounded response without aggregating `auditLogs`. For account verification, `users` tracks `emailVerified: boolean`; `POST /users/invites` dispatches an invitation email via `fastify.mailer.sendInviteMail` when `email` is provided and registering with a valid `inviteToken` sets `emailVerified: true` immediately, while open-registration accounts start with `emailVerified: false` (or reset to `false` on email change) and verify via single-use SHA-256 hashed `<verificationId>.<secret>` tokens at `POST /auth/verify-email/request` and `POST /auth/verify-email/confirm`.
