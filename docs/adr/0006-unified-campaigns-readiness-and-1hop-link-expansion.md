# Unified Campaigns, Note Readiness, and 1-Hop External Link Expansion

We unify evergreen **Notebooks** (`mode: 'notebook'`) and time-bound preparation **Campaigns** (`mode: 'campaign'`, `status: 'active' | 'archived'`, `targetDate: Date | null`, and creation-time `starterTemplate: 'interview' | 'exam'` or custom `starterFolders`) in the `notebooks` collection so Campaigns can be archived and reopened without duplicating containers. Every **Note** tracks `readiness: 'to_review' | 'in_progress' | 'mastered'` and `noteType: 'standard' | 'post_mortem'` across CRUD, WebSocket live updates, delta-sync, and CSV import/export, with `post_mortem` debrief notes excluded from Readiness denominators so logging retrospective notes never penalizes preparation scores. Container-scoped Mind Maps (`GET /notes/graph`), tree Readiness rollups (`GET /notebooks/tree`, `GET /notebooks/:id/tree`), Flashcard drills (`GET /flashcards/drill`), and Dashboard summaries (`GET /dashboard/summary`) expand 1-hop outgoing `links.targetId` (`includeExternal: true` by default), annotating linked canonical notes from evergreen Notebooks with `isExternal: true` and `homeNotebookId` so users never have to duplicate notes into a Campaign.
